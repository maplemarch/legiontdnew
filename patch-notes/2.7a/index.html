LTD Patch 2.7a

Legion TD NewEdition · อัปเดต 27 กันยายน 2569 · แก้บัคจากแพตช์ 2.7

1

แก้ค่ายูนิต

Orc Builder

Chaos Axe Master
Orc Builder
FIX
  • ค่าอัปเกรดใช้ค่าตามแพตช์ 2.7 แล้ว 280 → 400 ไม้

Naga Builder
FIX
  • ร่างที่ลงสนามได้ HP ตามแพตช์ 2.7 แล้ว 1,635 → 2,000
  • เดิมเปลี่ยนแค่ร่างป้อม ร่างที่ลงสู้จริงยังเป็นค่าเก่า
ค่าร่างป้อมไม่ตรงกับร่างลงสนาม
Tower form
FIX
  • ค่าที่แสดงตอนวางป้อมตรงกับยูนิตที่ลงสู้จริงแล้ว

  • Gnoll Savage ความเร็วโจมตี 0.91 → 0.80
  • Flaming Shooter ฟื้นมานา 12.5 → 15
  • Hellraiser ระยะโจมตี 435 → 450
Rifle Man
ร่างอัปเกรดของ Infantry

  • แก้ไอคอนที่ขึ้นเป็นสีเขียว นำรูปไอคอนจาก 2.6e กลับมาใส่ในแมพ
  • ไอคอนสกิล Penetration Shot, Calibrate Focus และ Assassinate กลับมาแสดงด้วย

ฟีเจอร์ใหม่

New Features
🚫
ส่งตัวที่ใช้ไม้ไม่ได้ตั้งแต่เวฟ 20
Wave 20
ADJUST
  • ตั้งแต่เวฟ 20 เริ่มเกิดจนจบเกม ส่งตัวจากบ้านที่ใช้ไม้ไม่ได้ทุกบ้าน
🪙
แปลงไม้เป็นทองตอนเริ่มเวฟ 20
Wave 20
NEW
  • พอเวฟ 20 เริ่ม ไม้ทั้งหมดแปลงเป็นทองอัตรา 20 ไม้ = 1 ทอง เศษที่ไม่ครบ 20 ปัดทิ้ง
  • หลังแปลงแล้ว ผู้เล่นทุกคนจะไม่ได้รับไม้อีกจนจบเกม
⚔️
Arena เมื่อผู้เล่นสองทีมไม่เท่ากัน
Arena Battle
NEW
  • ใช้เฉพาะยูนิตของผู้เล่นที่ยังอยู่ในเกม คนที่ออกไปแล้วไม่ถูกนำมาสู้
  • ถ้าคนไม่เท่ากัน ทีมที่คนเยอะกว่าจะส่งเฉพาะคนที่มี Value สูงสุด ให้จำนวนเท่ากับทีมที่คนน้อยกว่า
  • ตัวอย่าง 4 ต่อ 3: ทีมที่มี 4 คนส่งคนที่ Value อันดับ 1–3 ลงสู้
  • ใช้ทั้ง Arena หลังเวฟ 10 และหลังเวฟ 20
  • บอสไม่มาช่วยทีมที่คนน้อยแล้ว จะมาเฉพาะตอนที่อีกทีมไม่เหลือคนเลย
🧪
คำสั่งใหม่ในโหมดทดสอบ
Test Mode (tm)
NEW
  • ในโหมด tm พิมพ์ -wave x (x = 1–20) เพื่อให้เวฟถัดไปเป็นเวฟ x
  • ใช้ -wave แล้วระบบเตะตาม Value จะปิดสำหรับเกมนั้น
  • ก่อนเริ่มเวฟ เวลานับถอยหลังจะหยุดรอ พิมพ์ -start เพื่อเริ่มเวฟถัดไป
  • -rd สุ่มยูนิตใหม่ทั้ง 6 ตัว (โหมด pr)
  • -arenatest รัน test case 6 เคสของกติกา Arena ผู้เล่นไม่เท่ากัน แล้วบอก PASS/FAIL
  • -arenaout ให้ยูนิตของตัวเองไม่ลง Arena ครั้งถัดไป ไว้เช็กกับยูนิตจริง
